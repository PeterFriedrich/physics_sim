## 3. Technical Learnings
- ES modules do not load from `file://`: use `npm run serve` (`tools/serve.js`, zero-dependency).
- Unicode has no subscript *g*: `₉` is subscript nine. Canvas labels use `subText()` in `lib/canvas.js` with `F_g` syntax.
- `[hidden]` needed `display: none !important`, because `.transport { display: flex }` overrode the attribute.
- Playwright `text=` selectors also match the "Try this" prompts. Scope to `#sim-controls` / `#sim-transport`.
- Floating-point residue (x ≈ 1e-17 at equilibrium) is snapped by `snap(x, scale)` relative to the quantity's own scale. No absolute threshold, because charges and masses are legitimately 10⁻¹⁹ and 10⁻³¹.
- The global Playwright lives at `/opt/node22/lib/node_modules/playwright`; `verify-sims.js` falls back to that path.
